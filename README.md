# mhdshazwn.com

Personal portfolio of Mohd Shazwan Norisham, web designer and developer in Malaysia.

A static site (HTML, CSS, JavaScript) generated by a small Python script. Live at https://mhdshazwn.com.

## Edit and publish
1. Change text, projects, prices or images in `build/content.py` (images live in `build/img/`).
2. Run `python3 build/build.py`. The site is written to `site/`.
3. Commit and push to `main`. GitHub Actions publishes `site/` to GitHub Pages.

Text marked `PH("...")` in `content.py` is a placeholder and is left off the site until it is replaced.
See `BUILD-NOTES.md` for details.
